# おでかけデッキ

カフェやごはん屋さんの候補を集めて、友だちとその日の行き先を決めるためのサイトです。

- 「お店を追加」から、店名・ジャンル・エリア・リンク・メモを登録します。最初の3件は架空のサンプルです。
- 「候補に入れる」で今日のデッキに追加します。「1枚引く」は、お店一覧の絞り込み結果や、今日のデッキの中からカードを選びます。
- 「今日のデッキ」の共有リンクを送ると、選んだお店とメモを相手が開けます。相手が自分のリストに保存することもできます。
- お店の「詳細を見る」から「おすすめに追加」を選び、「わたしのおすすめ」に一言を添えて保存できます。共有リンクには選んだお店の名前、ジャンル、エリア、登録済みの Google マップリンク、おすすめの一言が含まれます。
- お店のカードと候補はブラウザに保存されます。共有リンクには選んだカードの内容が入るため、共有相手に見せたい情報を記入してください。

## 開発と公開

HTML、CSS、JavaScriptだけで動きます。ルートで `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開くと確認できます。

GitHub Pages の公開元は `main` ブランチのルートです。`main` の更新で公開サイトが再デプロイされます。

## 画像

トップのコーヒーとケーキは ImageGen で作成したイメージです。お店のカードは店名、ジャンルまたは保存リスト名、登録済みのエリアとメモを表示します。店舗の写真は「詳細を見る」から Google マップを開いて確認できます。

## Google マップの保存済みリスト

「マップから取り込む」で、Google Takeout の「保存済み」を解凍したリストごとの CSV を選びます。差分を確認して保存し、次回は同じリスト名で更新できます。ブラウザ内で処理し、CSV のメモは共有リンクに含めません。

重複の判定、再取り込み、削除と復元の扱いは [Google マップ取り込みの仕様](docs/google-maps-import.md) を参照してください。
