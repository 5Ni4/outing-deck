# Google マップの保存済みリスト取り込み

## 対象と操作

Google Takeout の「保存済み」から書き出したリストごとの UTF-8 CSV を使う。ZIP を解凍し、取り込みたい CSV を1つ選ぶ。ファイル名をリスト名の初期値にする。次の書き出しを同じ名前で取り込むと、同じリストの更新になる。別アカウントで同名リストがある場合は、別々の名前で取り込む。

店名と Google マップのリンクをカードに反映する。リスト名で絞り込める。Google マップのメモはカード詳細で本人だけが見る。住所やジャンルが CSV にないときは空欄・未分類で登録し、手入力できる。営業時間、口コミ、評価、写真はリンク先で確認する。

CSV はブラウザ内で読み取る。ファイルや保存済みリストは GitHub や外部サービスにアップロードしない。既存の手入力カード、候補、以前に作成した共有リンクを引き続き使える。新規共有リンクには選んだカードの内容と Google マップへのリンクを含め、CSV のリスト名とメモは含めない。

## 重複と更新

| 判定 | 取り込み結果 |
| --- | --- |
| リンク内の店舗 ID、同じ短縮リンク、または同じリストで登録済みの行が一致 | 同じカードを使い、リストとマップのメモを更新する。複数リストに入ってもカードは1枚。 |
| 名前だけが一致、または既存の候補が複数 | 保存前に表示する。既存カードに紐づけるか別店舗として追加する。指定しない行は見送る。 |
| 手入力の店名・ジャンル・エリア・メモ・リンク | 取り込みで上書きしない。 |
| タイトルがない行、店舗のリンクがない行、Google マップ以外の保存項目 | 除外して件数を表示する。CSV の構文やヘッダーが不正なら保存前に止める。 |

## 削除

- Google マップのリストから外したお店は、同じ名前の CSV の再取り込みで「リストから外れた」と表示する。チェックして適用したときだけ、そのリストの関連付けを外す。カード、手入力の内容、他のリスト、今日のデッキは残る。見送り・除外があった回はリストの関連付けを外せない。
- お店カードの「削除」はサイトのゴミ箱に移し、今日のデッキからも外す。あとからゴミ箱で復元できる。取り込みで同じ店が見つかっても削除済みのカードは復元しない。
- サイトでの操作によって Google マップ側のデータは変更されない。すでに送った共有リンクは、作成時点のカードの控えとして開ける。

## 確認条件

取り込みの確認画面で新規・既存・要確認・見送り・リストから外れた件数が分かる。同じファイルを再読込してもカードは増えず、同名の別支店を明示的に追加できる。リストの関連付けの解除とカード削除の結果が異なる。削除後の再取り込み、復元、旧データ、共有先での非公開項目の扱いを確認する。
